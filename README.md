# PySpark Query Optimization

Hands-on PySpark work focused on improving Spark query and data processing performance using practical optimization techniques.

## Topics Covered

- Data Scanning Optimization
- Delta Lake Optimization
- Partition Pruning
- Salting for Data Skew
- Adaptive Query Execution (AQE)
- Reducing Unnecessary Data Scans
- Spark Query Performance Tuning

## Technologies

- PySpark
- Apache Spark
- Azure Databricks
- Delta Lake
- Python

## Repository Structure

The repository contains individual PySpark scripts covering different query optimization and Spark performance tuning scenarios, with examples focused on data scanning, Delta Lake optimization, partition pruning and data skew handling.
